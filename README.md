# Yuki Learn Lite

Aplicación Android educativa y gamificada orientada al aprendizaje de fundamentos de programación.

## Proyecto académico

- Curso: Aplicaciones Móviles
- Semestre: VI
- Periodo: 2026-II

## Tecnologías

- Android Studio
- Java
- XML
- SQLite

## Características previstas

- Ruta de aprendizaje gamificada
- 3 unidades
- 6 lecciones
- Ejercicios interactivos
- XP y niveles
- Sistema de estrellas
- Progreso local mediante SQLite
- Modo claro y oscuro
- Personajes Yuki y Luna
